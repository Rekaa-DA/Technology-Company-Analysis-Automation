# 🌐 API Data Collection

## Objective

Collect GitHub repository data from leading technology companies using the GitHub REST API.

## Data Source

- GitHub REST API
- https://api.github.com

## Technology Used

- Python
- Requests Library
- JSON
- GitHub API

## Companies Collected

- Microsoft
- Google
- Oracle
- IBM
- SAP
- Salesforce
- Snowflake
- SAS

## Data Collected

The following repository information was collected:

- Company
- Repository Name
- Programming Language
- Stars
- Forks
- Watchers
- Open Issues
- Repository Size
- License
- Archived Status
- Created Date
- Updated Date
- Repository URL

## Output

The collected data was exported as a raw dataset for further data cleaning and analysis.

## Files

- githubcode.py
- github_raw_dataset.csv
