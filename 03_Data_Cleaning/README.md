#  Data Cleaning

## Objective

Clean the raw GitHub repository dataset before storing it in the database and using it for dashboard development.

## Cleaning Tasks

- Removed duplicate records
- Handled missing values
- Standardized column names
- Converted data types
- Cleaned date columns
- Validated repository data

## Tools Used

- Python
- Pandas
- NumPy

## Input

github_raw_dataset.csv

## Output

github_cleaned_data.csv

## Result

The cleaned dataset is ready for SQL storage and Power BI dashboard analysis.
