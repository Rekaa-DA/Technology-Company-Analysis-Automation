# 📋 Project Planning

## Project Title

GitHub Repository Data Automation using n8n

## Project Description

This project automates GitHub repository data collection from multiple technology companies using the GitHub REST API. The collected data is cleaned, transformed, stored, and visualized through an end-to-end analytics pipeline.

## Technology Stack

- Python
- GitHub REST API
- MySQL
- n8n
- JavaScript
- Google Sheets
- Power BI
