# 📋 Project Planning

## 📌 Project Title

GitHub Repository Data Automation using n8n

---

## 📊 Project Overview

This project automates the collection, cleaning, storage, and visualization of GitHub repository data from leading technology companies.

The automation pipeline combines Python, MySQL, n8n, Google Sheets, and Power BI to reduce manual effort and automatically update analytical dashboards.

---

## 🎯 Project Objectives

- Automate GitHub repository data collection.
- Clean and standardize repository data.
- Store structured repository information.
- Build an end-to-end automation workflow.
- Automatically update reporting dashboards.
- Demonstrate practical Data Analytics automation.
